# 💤 Drowsiness Detection System

This project detects driver drowsiness in real-time using computer vision techniques. By analyzing eye blink rate and gaze direction, it issues alerts to prevent fatigue-related accidents.

## 💡 Features
- Real-time video capture with OpenCV
- Eye aspect ratio (EAR) detection for drowsiness
- Audio alert for safety intervention

## 🛠 Tech Stack
- Python
- OpenCV
- Dlib
- imutils

## 🚀 Getting Started
1. Install dependencies: `pip install -r requirements.txt`
2. Run: `python drowsiness_detection.py`
